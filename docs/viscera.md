# 剧情肢体掉落提示

剧情指南在每次出现区域名称时展示部件效果和掉落 BOSS，
包括步行进入、传送点、传送门返回，以及 `{area|...}` 区域引用。
同名的不同幕区域按世界区域 ID 区分；同一区域反复进入时会重复展示，方便随时查看。
提示适用于开荒、强盗、图书馆分支和自定义路线。

“菜单 → BD 配置”中的“显示肢体掉落提示”开关可统一控制所有肢体信息。
默认关闭，选择会保存在浏览器中，刷新后继续生效；旧版未保存该选项的设置也默认关闭。

数据来自 [PoEDB Viscera](https://poedb.tw/cn/Viscera)，
效果与 BOSS 名称分别取自简中、繁中页面。点击效果可打开对应部件详情，
悬停可查看部件名称、LOW / 未分档说明及概率掉落说明。
长效果允许换行，不受地图名称不换行样式影响。

采集规则：

- 有 LOW 档时仅采用 LOW，不采用 MED、HIGH、QUEEN。
- 未分档但注明剧情幕数、BOSS 和地图时也纳入剧情提示，保留全部原文效果及编号。
- 同一部件的多条效果合并展示；同一地图的多个部件全部列出。
- 未注明剧情幕数或地图的条目跳过，不根据名称猜测掉落地点。
- 原始文本缺少可靠译名时保留英文。

快照包含 128 个部件掉落条目，覆盖 122 个剧情区域；当前路线未经过的区域不额外添加步骤。
数据在构建时打包，不需要玩家打开页面时访问 PoEDB。

PoEDB 列表的已核对地点修正保存在生成脚本的 `areaOverrides` 中：
欧克对应第二幕湿地，日月女神对应第八幕港湾大桥，隐蔽底港对应第八幕，
The Black Heart 战斗区域归于第九幕腐烂内核。修正的区域页面证据见脚本注释。

更新数据：

```powershell
node scripts/sync_viscera.mjs
```

离线重建时可用 `--input-dir <目录>` 指定保存了 `viscera-us.html`、
`viscera-cn.html`、`viscera-tw.html` 的目录。
可设置 `VISCERA_RETRIEVED_AT` 环境变量固定采集日期。
遇到未知区域、页面结构变化或简繁条目不匹配时，生成器报错而不写入不完整数据。

验证：

```powershell
node --import tsx --test web/tests/viscera.test.ts
npm run build
```
